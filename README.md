# Национальный художественный музей Республики Беларусь — Интерактивный гид

Клиентское веб-приложение для составления и расчета персонального маршрута по залам постоянной экспозиции Национального художественного музея Республики Беларусь (г. Минск, ул. Ленина, 20).

## Функциональность

- **Интерактивный каталог экспонатов**: сакральное искусство Полесья XVII в., слуцкие пояса, сарматские портреты Радзивиллов, классическое и академическое искусство XIX в., модерн, символизм и монументальное искусство XX в.
- **Умная фильтрация**: по залам, категориям и эпохам создания с мгновенным предфильтром при переходе по кнопкам.
- **Автоматический хронометраж**: расчет продолжительности осмотра с учетом времени переходов между залами (+5 мин) и выбором комфортного темпа.
- **Контроль лимита времени**: мягкое предупреждение о превышении и инструменты оперативной корректировки.
- **Оформление визита и карта-пропуск**: валидация контактных данных и генерация персонального цифрового пропуска.

## Технологический стек

- React 19
- Vite
- Framer Motion
- Чистый CSS3 (без сторонних UI/CSS-библиотек)
- Lucide React

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка для продакшена:

```bash
npm run build
```
